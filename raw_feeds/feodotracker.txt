      <section id="ip-blocklist">
        <h2>Botnet C2 IP Blocklist</h2>
        <hr>
        <p>Dridex, Heodo (aka Emotet), TrickBot, QakBot (aka QuakBot / Qbot) and BazarLoader (aka BazarBackdoor) botnet command&amp;control servers (C2s) usually reside on compromised servers and such that have been rented and setup by the threat actor itself for the sole purpose of botnet hosting. Feodo Tracker offers a blocklist of IP addresses that are associated with such botnet C2s. It can be used to block botnet C2 traffic from infected machines towards hostline servers on the internet that are under the control of cybercriminals.

        <p>To keep the false positive rate as low as possible, <strong>an IP address will only get added to the blocklist if it responds with a valid botnet C2 response</strong></p>
        <p>The Botnet C2 IP Blocklist gets <strong>generated every 5 minutes</strong> and is available in the plain-text and JSON format. We recommend you to update the list at <strong>least every 15 minutes</strong> (or even better: every 5 minutes) to receive the best protection against Dridex, Emotet, TrickBot, QakBot and BazarLoader.</p>
        <div class="alert alert-success mt-4" role="alert">
          <h4 class="alert-heading">Recommended IP blocklist</h4>
          If you want to block botnet C&amp;C IP addresses but avoid false positives, I highly recommend you to use the following blocklist as it only contains <strong>active</strong> botnet C&amp;C servers or such that have been active in the past hours. Although false positives can happen on this blocklist, the false positive rate should be low.</p>
          <p><a class="btn btn-primary" href="/downloads/ipblocklist_recommended.txt" title="download Botnet C2 IP Blacklist (recommended)" target="_parent" role="button">Plain-Text</a> <a class="btn btn-primary" href="/downloads/ipblocklist_recommended.json" title="download Botnet C2 IP Blacklist (recommended) in JSON format" target="_parent" role="button">JSON</a></p>
        </div>

        <p>We also have custom formats of the blocklist available for <kdb>McAfee Web Gateway</kdb> and <kdb>Palo Alto Firewall</kdb>:</p>
        <p><a class="btn btn-primary" href="/downloads/ipblocklist_recommended_mcafee.txt" title="Feodo Tracker Blocklsit for McAfee Web Gateway" target="_parent" role="button"><img src="/images/icons/mcafee.png" width="16px" height=16px" alt="McAfee"> McAfee Web Gateway</a> <a class="btn btn-primary" href="/downloads/ipblocklist_recommended_paloalto.txt" title="Feodo Tracker blocklist for Palo Alto Firewall" target="_parent" role="button"><img src="/images/icons/paloalto.png" width="16px" height=16px" alt="Palo Alto"> Palo Alto Firewall</a></p>

Unlike the IP blocklist above, these datasets do not only contain additional information on tracked botnet C2s but also IP addresses that were acting as a botnet C2 within the <strong>past 30 days</strong>.</p>

        <h2>Suricata Botnet C2 IP Ruleset</h2>
        <hr>
        <p>The Suricata Botnet C2 IP Ruleset contains botnet C2s tracked by Feodo Tracker and can be used for both, <a href="http://suricata-ids.org/" target="_blank" title="Suricata IDS/IPS">Suricata</a> and <a href="https://www.snort.org/" target="_blank" title="Snort IDS/IPS">Snort</a> open source IDS/IPS. If you are running Suricata or Snort, you can use this ruleset to detect and/or block network connections towards hostline servers (IP address:port combination).</p>
        <p>The ruleset gets <strong>generated every 5 minutes</strong>. We recommend you to update the IDS ruleset at <strong>least every 15 minutes</strong> (or even better: every 5 minutes) to receive the best protection against Dridex, Emotet, TrickBot, QakBot and BazarLoader.</p>
        <div class="alert alert-info" role="alert">
          <h4 class="alert-heading">Note</h4>
          <p>As IP addresses are getting recycled and reused, this blocklist only botnet C2s that are either active or that have been last seen in the <strong>past 30 days</strong>. The false positive rate for this blocklist should therefore be low.</p>
        </div>
